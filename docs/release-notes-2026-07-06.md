# What's New — July 6, 2026

A summary of recent improvements to Sewed Items.

---

## Sewed Items

### Payslip dialog improvements
- Each category line on the payslip now shows the **date the sewed item was created** in small text beside the category name, so batches from different days are easy to tell apart.
- The payslip dialog is now **scrollable** — long payslips (even 50+ items) stay within the screen instead of overflowing, and printing still outputs the full payslip, not just the visible part.
