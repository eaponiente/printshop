# What's New — July 1, 2026

A summary of recent improvements across Sublimations and Sewed Items.

---

## Sublimations

### Add Items to Existing Sublimation
- The dialog now opens with **no categories pre-selected**. Previously it copied over the original order's categories; now you start from a clean slate and add only the categories that belong to the additional batch.

### Sublimations List — User Filter
- The **User filter is now sorted alphabetically by first name**, making it easier to find a specific person.
- When you **select a branch**, the User filter now only shows users from that branch. Clearing the branch selection restores the full list of users you have access to.

---

## Sewed Items

### Default Sorting
- The Sewed Items page now lists entries **newest first**, ordered by when each item was created, so the most recently added items appear at the top.
