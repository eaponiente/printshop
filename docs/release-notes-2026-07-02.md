# What's New — July 2, 2026

A summary of recent improvements to the Projects (Sales) module.

---

## Projects (Sales)

### Tabs split by settlement status
The list tabs have been reorganized so you can jump straight to a settlement status:

- **Paid** — the payments/collection view (money received, with the summary overview and print report). This is the renamed **Payments** tab.
- **Partial** — projects that have been partially paid.
- **Unpaid** — projects with no payment yet (previously the only non-payments tab).

### Status filter removed
- The **Status** dropdown in the filter bar has been removed. The three tabs above now cover that, so there's no longer a redundant status filter to set.
- All other filters (Search, Frequency, Date, Branch, Staff, Payment type) are unchanged.
